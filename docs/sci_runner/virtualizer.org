
** SCI Runner Virtualizer

**** Preface

A select few components aren't evaluated on the main thread.
They're offloaded to a secondary thread (or threads) to
avoid the computational load ever being placed on the
main thread.
So those components also need their own SCI runner
but for many of the namespaces they can be blanked out.
The naming scheme for this might shift in time.
