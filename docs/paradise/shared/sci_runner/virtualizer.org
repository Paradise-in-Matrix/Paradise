
** SCI Runner Virtualizer

**** Preface

A select few components aren't evaluated on the main thread.
They're offloaded to a secondary thread (or threads) to
avoid the computational load ever being placed on the
main thread.
So those components also need their own SCI runner
but for many of the namespaces they can be blanked out.
The naming scheme for this might shift in time.

(def virtualizer-context
  (factory/build-context
   :virtualizer
   {:!current-plugin         !current-eval-plugin
    :!overrides              state/!worker-overrides
    :!components             state/!worker-components
    :!slots                  nil
    :!virtualizer-pool       nil}
   virtualizer-namespaces))


(defn eval-virtualizer-plugin! [plugin-id code-str]
  (reset! !current-eval-plugin plugin-id)
  (try
    (sci/eval-string* virtualizer-context code-str)
    {:status :success}
    (catch :default e
      (js/console.error (str "Virtualizer Plugin Eval Error [" plugin-id "]:") e)
      {:status :error
       :error (ex-message e)})))
